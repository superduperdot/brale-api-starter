# Contributing

## Setup

```bash
pnpm install
pnpm -r typecheck
pnpm test
pnpm build
```

## Pull requests

- One topic per pull request.
- Run the gates in [AGENTS.md](./AGENTS.md) before you ask for review.
- Update `brain.md` and the README when behavior changes.
- A bug fix includes a regression test when that is practical.

## Docs

- [brain.md](./brain.md) — what is built
- [AGENTS.md](./AGENTS.md) — commands and guardrails
- Brale Playbook — patterns for the architecture named in `brain.md`
